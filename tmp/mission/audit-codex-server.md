# Server transcription runtime audit

## Architecture map

- **Dictation:** `/transcribe/dictate` accepts an authenticated multipart audio upload and returns text, model ID, inference time, and whether smart formatting applied. Parakeet MLX (`mlx-community/parakeet-tdt-0.6b-v2`, `parakeet-mlx` and `mlx`) loads and warms during server startup, then runs inference in a single-thread executor. ## Findings

- **P0 — Cross-user job access:** Meeting poll, download, and delete require an API key but never compare its user ID with the job’s stored `api_key_id`; an authenticated user with another job ID can read or delete its output. **Fix:** enforce ownership or admin authorization in all three handlers before exposing status, files, or deletion. `server/src/wispralt_server/routes/meeting.py:34` `server/src/wispralt_server/routes/meeting.py:124` `server/src/wispralt_server/routes/meeting.py:198` `server/src/wispralt_server/routes/meeting.py:225` `server/src/wispralt_server/jobs/store.py:69`
- **P1 — File mode still requires diarization:** `mode=file` skips speaker inference, yet the shared pipeline loads Pyannote and its gated model before choosing the single-channel branch; `HF_TOKEN` is also a required setting. **Fix:** split file transcription from meeting-model initialization so uploads load only their selected inference backend. `server/src/wispralt_server/config.py:31` `server/src/wispralt_server/meeting/pipeline.py:117` `server/src/wispralt_server/meeting/pipeline.py:383` `server/src/wispralt_server/meeting/pipeline.py:447` `server/src/wispralt_server/meeting/pipeline.py:521`
- **P1 — Unknown `/v1` models proceed:** The route logs an unrecognized model but does not return an error before Parakeet inference. **Fix:** return `model_not_found` and keep validation consistent with `/v1/models`. `server/src/wispralt_server/routes/v1_transcriptions.py:144` `server/src/wispralt_server/routes/v1_transcriptions.py:154` `server/src/wispralt_server/routes/v1_transcriptions.py:239` `server/src/wispralt_server/routes/v1_models.py:90`
- **P1 — Chunk assembly can accept missing indices:** Finalize checks the number and aggregate size of `chunk-*.part` files, then concatenates their sorted names, without verifying that every index from zero through `chunk_count-1` exists. **Fix:** construct and check the expected filenames before concatenation. `server/src/wispralt_server/routes/transcribe_file.py:394` `server/src/wispralt_server/routes/transcribe_file.py:525` `server/src/wispralt_server/routes/transcribe_file.py:533` `server/src/wispralt_server/routes/transcribe_file.py:554`
- **P2 — Mercury often returns raw text:** Startup disables it unless both `SMART_FORMAT_ENABLED` and the OpenRouter key are set; the caller must opt in, the input must reach 80 words, and the default whole-request budget is 600 ms. Empty/unrecognized `content` and `reasoning`, HTTP errors, timeouts, or cleaned text outside 70–110% of the original word count all fall back to raw text. **Fix:** expose a useful applied/fallback reason in telemetry and tune the budget and threshold with measured results. `server/src/wispralt_server/main.py:270` `server/src/wispralt_server/config.py:114` `server/src/wispralt_server/config.py:124` `server/src/wispralt_server/config.py:145` `server/src/wispralt_server/routes/dictate.py:124` `server/src/wispralt_server/smart_format/mercury_client.py:79` `server/src/wispralt_server/smart_format/mercury_client.py:168` `server/src/wispralt_server/smart_format/mercury_client.py:188` `server/src/wispralt_server/smart_format/mercury_client.py:231` `server/src/wispralt_server/smart_format/mercury_client.py:250`
